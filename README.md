# 牌局小账本（打牌记账微信小程序 · 房号制）

微信小程序 · 原生框架 + 微信云开发。房主开房生成 4 位房号和小程序码，牌友扫码/输房号/点分享卡片进房，各自用微信头像昵称，**各人记各人的**，实时汇总排行，结束时给出最少笔数转账方案。

## 首次部署（一次性，约 15 分钟）

1. **导入项目**：微信开发者工具 → 导入 → 选择本目录（AppID 已填好）
2. **开通云开发**：工具栏「云开发」→ 开通（免费基础版）
3. **创建 4 个集合**（云开发控制台 → 数据库 → 新建）：
   - `users`（用户头像昵称）
   - `rooms`（房间）
   - `members`（房间成员）
   - `records`（每条记分）
   - 权限都选「**所有用户可读，仅创建者可写**」
4. **部署云函数**（关键步骤，两个都要）：
   - 在开发者工具左侧文件树找到 `cloudfunctions/login` → 右键 →「上传并部署：云端安装依赖」
   - 同样方式部署 `cloudfunctions/qrcode`
   - qrcode 已配置 `wxacode.getUnlimited` 权限，用于生成进房小程序码
5. 编译运行：首页先填头像昵称 → 保存 → 「我要开房」

## 使用流程

1. **开房**：一键生成 4 位房号（如 `X7KD`）+ 小程序码，弹窗里可以"转发给好友"
2. **进房**：牌友三种方式任选——扫小程序码 / 首页输房号 / 点分享卡片
3. **记账**：每个人点「记一笔」，自己填这局赢/输多少（正/负），房间内实时同步排行
4. **结算**：房主点「结束房间并结算」，自动算每人净积分 + 最少笔数转账方案
5. **战绩**：底部 tab，按人汇总房间数、局数、胜率、单局最大输赢、累计净积分；首页显示好友排名

## 数据结构

- `users`: `{ openid, nickname, avatarFileID, createdAt }`
- `rooms`: `{ code, ownerOpenid, status('ongoing'|'ended'), qrFileID, createdAt, endedAt }`
- `members`: `{ roomId, openid, nickname, avatarFileID, joinedAt }`
- `records`: `{ roomId, openid, nickname, delta, createdAt }`（昵称快照，改昵称不影响历史）

## 上线发布

1. 工具栏「上传」→ 公众平台「版本管理」→ 提交审核（类目：工具-信息查询；文案全程用"积分"）
2. 备案通过后发布；或不上线，用「体验版」二维码给牌友用
